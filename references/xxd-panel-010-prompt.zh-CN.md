# XXD Panel 010｜粗黑干媒介童书剪影生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

只处理当前任务明确提供的这一张源照片。先观察并锁定主体或不可拆分的互动关系、轮廓、姿态、动作、方向、距离、功能、情绪与最关键局部；至少保留三个源图专属识别线索。不要借用旧成品、样张或其他输入的主体、文案和构图。

## 核心转译

把主体或最重要的互动关系压缩为一个圆润、敦厚、略带稚拙感的粗黑剪影视觉单元。不要机械描摹。可适度放大头部、主要轮廓或最有记忆点的局部，但必须服务于识别。多人或多物时保留最重要的互动，把它们视为一个整体，不平均分散焦点。

只使用近乎纯白的纸面底与浓黑蜡笔、炭笔或干擦痕迹。禁止彩色、彩色点缀、大面积灰色、灰阶渐变与写实明暗。黑色不是光滑实心矢量块，而由短促、有力度、反复涂抹的干媒介笔触形成；保留纸张颗粒、断笔、压痕、边缘毛糙、轮廓轻微摇晃与不完整、浓淡不均和局部露白。

在黑色剪影内部突然切出一个最能强化辨识的白色特征区：脸部、眼睛周围、窗洞、器皿开口、动物面部、物件核心结构或其他源图专属局部。只用极少黑点、短线或符号补足表情与功能，不画写实五官或精密内部结构。

## 空间与叙事

保持大面积纯净留白与一个主要视觉关系。主体可居中悬浮、轻微偏置、局部裁切或靠近下方；只允许一条粗糙地面摩擦线、几根短线或极少环境符号提示空间。

草叶、雨丝、烟气、桌面、影子、道路、风及其他环境信息都压缩为最少的蜡笔记号。让一个姿态、动作、距离或关系承担叙事。拒绝复杂场景、多个同等焦点、装饰边框与卡通贴纸感。

整体在童稚、温软、安静、幽默与孤独之间保持微妙平衡，像由高级设计工作室重新编辑的旧黑白童书；不能变成恐怖黑影、品牌图标、可爱商品插画或模板。

## 文案与字体

服从已锁定的自动文案、用户准确文案或无文字模式，以及目标语言／地区。用户准确文案逐字保留，不改写、不翻译、不纠错、不补字；无文字时不生成任何伪文字。

自动文案从源图可见或有依据的情绪、动作、关系、时间或微小故事中提炼一个简短标题，再按需增加 1–2 组极小辅助文字。允许有依据的金句式短句、编号或章节号；日期、地点、出处、编号等事实性信息必须由用户提供或可靠确认，绝不伪造。

字体以克制的高级编辑小字为主，只加入极少量笨拙手写、蜡笔字或不完全规整字形。文字可贴着地面线、沿动作方向延伸、躲在白色留白、轻微压住轮廓、卡在两个主体的负形之间，或由一条细线连接编号与主体。不要大标题压画面、商业口号、假外语或与图形分离的数字覆盖层。

## 模式与验收


硬性验收：一个圆润敦厚的粗黑剪影单元；至少三个源图线索；一个决定性的内部白色特征区；近白纸面占最大面积；只有浓黑干媒介且无彩色、灰阶渐变或写实明暗；短促有力笔触与真实纸张痕迹；环境记号极少；一个姿态、动作、距离或关系承担叙事；文字短、准、属于这张图并嵌入构图；无光滑矢量、精密线稿、厚涂、3D、贴纸感、照片残片或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
