# XXD Panel 010 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ1枚の独立したハイエンドなデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図を採用し、上下2つの領域の高さは厳密に1:1とし、それぞれ画面の50%を占めます。

上半分には元の写真を残し、被写体のアイデンティティ、構造、姿勢、リアルな質感、自然な光と影、元の色彩の雰囲気を維持し、わずかにハイエンドな写真のカラーグレーディングのみを施して、アート雑誌、インディペンデント出版物、展覧会写真のような質感を持たせます。画面比率に合わせるため、空、地面、または環境背景を自然に拡張できますが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別性の高い被写体、輪郭、姿勢、物語上の関係性を抽出し、ミニマルで粗い黒のドライメディアによるシルエットイラストとして再構成します。写真のディテールを機械的になぞるのではなく、被写体を丸みがあり、どっしりとして、やや稚拙さのある簡略化された形に圧縮します。頭部、主要な輪郭、または最も記憶に残る部分を適度に拡大し、ごく少ない情報でも元の対象を一目で識別できるようにします。写真に複数の被写体が含まれる場合は、最も重要な相互関係を残し、焦点を均等に分散させるのではなく、それらを一つの総合的な視覚単位として扱います。

下半分には、ほぼ純白の紙面の地 + 濃い黒のクレヨン、木炭、または乾擦の跡だけを使用し、色彩もグレースケールのグラデーションも使用しません。黒い形は滑らかで塗りつぶされたベクターの塊ではなく、短く力強いクレヨンの反復塗りによって形成し、紙の粒子、途切れた筆致、圧痕、粗い縁、濃淡のむら、部分的な白抜けを残します。輪郭はわずかに揺らぎ、不完全で不正確なものとし、画面に本物の手作業感を保ちます。

被写体の最も重要な識別特徴は、「黒いシルエットの中から突然切り出された白い特徴領域」によって強調できます。たとえば、顔、目の周囲、窓の開口部、器の口、動物の顔、物体の中核構造、または最も識別性の高い部分などです。さらに、ごく少数の黒い点、短い線、または記号で表情とディテールを仕上げます。写実的な顔立ちや精密な構造を追求せず、黒と白の間に直接的で、面白く、強い識別関係を生み出します。

構図は、大面積の清潔な余白 + 一つの主要な視覚関係に保ちます。被写体は中央に浮かせても、わずかにずらしたり、部分的にトリミングしたり、画面下部に寄せたりしてもよく、粗い地面の摩擦線1本、数本の短い線、またはごく少数の環境記号だけで空間を示唆します。草葉、雨筋、煙、卓上、影、道路、風、その他の環境情報はすべてごく少数のクレヨン記号に圧縮し、背景を静かで広々と保ちます。全体として複雑な場面を追求せず、一つの姿勢、動作、距離、または関係に主要な物語を担わせます。

ハイエンドな編集感と童話絵本の趣が共存する、少量の小さな文字システムを残します。場所や物体の名前だけを書くのではなく、写真の感情、動作、関係、時間、または小さな物語から、ユーザー指定の対象言語で短いタイトルを抽出し、番号、内容に合う印象的な一文、章番号、または極めて短く控えめなコピーを組み合わせます。文字は抑制された小さな印刷文字でもよく、ごく少量の不器用な手書き、クレヨン文字、または完全には整っていない字形を加え、もともとこのイラストに属していたかのようにします。

文字は図形と巧みな関係を結ぶ必要があります。地面の線に沿って並べたり、被写体の動作方向に沿って伸ばしたり、大きな余白の中に隠したり、輪郭とわずかに重ねたり、二つの被写体の間のネガティブシェイプにはめ込んだり、細い線で番号と被写体をつないだりできます。「一つの短いタイトル + 1–2組の極小の補助文字」だけに保ち、文字を普通のポスター見出しではなく構図のリズムの一部にします。

全体として、黒は粗く、白は清潔に、形は簡潔に、質感は荒くという視覚的特徴を示し、童心、柔らかさ、静けさ、ユーモア、孤独の間に微妙なバランスを保ちます。ハイエンドなデザインスタジオが再編集した古い白黒の童話絵本のように仕上げます。滑らかなデジタル輪郭線、精密な線画、写実的な光と影、厚塗り、3D効果、色彩、大面積のグレー描画、カートゥーンステッカー感、テンプレート化された商業イラストは避けます。
